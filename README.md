# BorrowHub

BorrowHub is a web-based community rental platform developed for the ICT1209 Web Technologies Mini Project.

## Features
- User Registration & Login
- Browse Rental Items
- List Items for Rent
- Rental Request Management
- Contact Form

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL
- Git & GitHub
